# Phron provider

Manage Phron Servers and Object Storage through the Phron API, signed in as an API client (an OAuth client-credentials machine user of your Organization).

## Credentials

The provider signs in as an **API client**: an OAuth client-credentials machine user of your Organization, created on the console's API clients page (an Organization Admin makes one, picks its Role, and sees the client ID and secret once). The page also shows the project id used in the scope. The Role of the API client decides what the provider may do: a Viewer cannot create or delete anything, and a Developer can manage Servers, SSH keys, buckets and its own keys but cannot delete a bucket (destroying a bucket needs the Admin Role).

Either `project_id` or `scope` is required.

## Secrets live in the state

`phron_storage_key.secret_access_key` is returned by the API once, at creation, so Terraform keeps it in the state file (marked sensitive, but stored in plain text). `phron_server.user_data` is kept from your configuration (the API never returns it) and is also marked sensitive. Store the state in a backend that encrypts it and restricts who can read it, and do not put secrets in `user_data`.

## Example usage

```terraform
terraform {
  required_providers {
    phron = {
      source = "phron-net/phron"
    }
  }
}

# Credentials come from PHRON_CLIENT_ID, PHRON_CLIENT_SECRET and
# PHRON_PROJECT_ID (all shown on the console's API clients page).
provider "phron" {}
```

## Schema

### Optional

- `client_id` (String) The API client's client ID (shown once on the console's API clients page). Defaults to the PHRON_CLIENT_ID environment variable.
- `client_secret` (String, Sensitive) The API client's client secret. Defaults to the PHRON_CLIENT_SECRET environment variable.
- `endpoint` (String) The API base URL. Defaults to the PHRON_ENDPOINT environment variable, then https://api.phron.net.
- `project_id` (String) The Phron project id shown in the scope on the console's API clients page. When set, the OAuth scope is built from it. Defaults to the PHRON_PROJECT_ID environment variable. Ignored when scope is set.
- `scope` (String) The complete space-separated OAuth scope, as shown on the console's API clients page. Overrides project_id. Defaults to the PHRON_SCOPE environment variable.
- `token_url` (String) The OAuth token endpoint. Defaults to the PHRON_TOKEN_URL environment variable, then https://auth.atestum.com/oauth/v2/token.
